⚠️ Common Pitfalls

🚫 Visual vs Actual
A cell might display $10.00 but actually contain 10. LEN counts the value (2 chars: "1", "0"), not the format (6 chars).
🚫 Invisible Spaces
If LEN("A") returns 2, you likely have a trailing space ("A "). Always use TRIM if counts look wrong.
