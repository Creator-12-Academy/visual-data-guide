🔠 Text Functions

Clean, combine, and manipulate strings. Master the art of string theory in Excel.

🧹 Cleaning
01. TRIM
Remove extra spaces. Cleans leading, trailing, and double spaces between words.
⬅️ Essential
02. LEFT / RIGHT
Extract specific parts of a text string from the start (Left) or end (Right).
✂️ Extraction
03. MID
Extract characters from the middle of a string. Perfect for pulling IDs or codes.
📏 Basic
04. LEN
Count the characters in a cell. Useful for validation (e.g., ensuring a ZIP code is 5 digits).
🔎 Utility
05. FIND / SEARCH
Locate the position of a substring. FIND is case-sensitive; SEARCH is not.
🔗 Essential
06. CONCAT / TEXTJOIN
Join text strings together. TEXTJOIN is the modern hero that handles delimiters easily.
🔄 Crucial
07. SUBSTITUTE
Swap specific text for new text. "Replace 'Old' with 'New'". Great for cleaning data.
📍 Advanced
08. REPLACE
Swap text based on position. "Replace 3 characters starting at position 5".
🎨 Formatting
09. TEXT
Format numbers as text strings. E.g., Convert 0.5 to "50%". Critical for concatenating numbers.
🔠 Formatting
10. UPPER / LOWER / PROPER
Change text casing. Convert to ALL CAPS, all lowercase, or Title Case.
