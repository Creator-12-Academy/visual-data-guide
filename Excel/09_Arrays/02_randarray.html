💻 Formula Structure

=RANDARRAY([rows], [cols], [min], [max], [integer])
  • 1. Rows/Cols: Grid size.
  • 2. Min/Max: Range of values.
  • 3. Integer: TRUE for whole numbers, FALSE for decimals.
-- Generate Random Grid
=RANDARRAY( 5, 3, 1, 100, TRUE )
