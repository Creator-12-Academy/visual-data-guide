💻 Formula Structure

  • 1. Number: The value to round (22.35).
  • 2. Significance: The multiple to snap to (5).

⚠️ Common Pitfalls

🚫 Significance vs Digits
ROUND uses decimal places (0, 1, 2).
CEILING uses multiples (0.05, 1, 5, 10).
Use CEILING for pricing logic (e.g., psychological pricing ending in .99 or .95).
🚫 Negative Numbers
Older Excel versions have bugs with negative numbers in CEILING. Use the modern CEILING.MATH function for consistent behavior.
