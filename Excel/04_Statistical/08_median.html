⚠️ Common Pitfalls

🚫 MODE Errors (#N/A)
If all numbers are unique (e.g., 1, 2, 3), MODE returns an #N/A error because no number is "most frequent."
🚫 Median vs Average
Median is better for Salary/House Price data because it ignores Outliers (extreme values) that skew the Average.
