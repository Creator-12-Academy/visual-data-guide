💻 Formula Structure

=IF(logical_test, value_if_true, value_if_false)
  • 1. Logical Test: The question (e.g., Sales > 5000).
  • 2. If True: What to do if YES (e.g., "Bonus").
  • 3. If False: What to do if NO (e.g., "No Bonus").

⚠️ Common Pitfalls

🚫 Missing Quotes
Text results must be wrapped in quotes (e.g., "Yes"). Numbers do not need quotes.
✅ Fix: Use "Passed", not Passed.
🚫 Wrong Operator
Using ">" (Greater Than) when you meant ">=" (Greater Than or Equal To).
✅ Fix: Double check edge cases (e.g., exactly 5000).
