⚠️ Common Pitfalls

🚫 AND inside IF
You cannot write IF(A1>5 AND B1<10).
You MUST write IF( AND(A1>5, B1<10), ... ).
🚫 OR Logic
OR returns TRUE if at least one condition is met. It only returns FALSE if all fail.
